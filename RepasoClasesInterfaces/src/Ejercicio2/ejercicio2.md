Haz lo mismo pero para implementar en una Pila.

▪ Una pila (stack) es una estructura de datos que funciona siguiendo el principio LIFO (Last In, First Out): el último elemento que entra es el primero en salir.
Ejemplo: piensa en una pila de platos: el último plato que colocas encima es el primero que vas a sacar.
